7. The RTL Module of Fully Connected
The result of the max pooling and ReLU operation in layer two is a 4x4 by three feature map.
This feature map will be flattened into a one by 48 input for the fully connected layer.
Then it will be multiplied with a set of weights followed by bias addition to produce an output with ten neurons.
So the operations involved in this fully connected module are multiplication and addition.
The circuit used to implement the fully connected module is similar to the convolution calculation module.
This is the basic version of the circuit without pipeline registers, which results in a long critical path.
To improve this, we use a pipelined version where the circuit is divided into several stages, resulting in a shorter critical path for the final design.

To implement this, we use a buffer with ten elements to temporarily store the values from the fully connected module.
