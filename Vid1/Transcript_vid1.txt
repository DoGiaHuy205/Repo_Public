Neural networks are loosely inspired by the structure and function of the human brain, especially how neurons communicate with each other.

The weights in a neural network are randomly initialized and then learned during the training process.
That's what makes the network smart.
Over time, neural networks consist of multiple neurons organized into layers, input layer, hidden layers, and output layer.
This kind of network is also called fully connected.
Every neuron in one layer is connected to every neuron in the next layer.
Nothing is left out.
The term deep learning generally refers to a type of neural network that has more than two hidden layers.

This kind of network is fine for small sized images, but has drawbacks with large sized images.
So we have an improved architecture called a convolutional neural network CNN.
So what is the problem with neural networks?
Well, images are not just a collection of random pixels.
They have spatial relationships.
Nearby pixels are more likely to be related to each other than distant pixels.
In a fully connected network, each pixel is treated independently, with no understanding of the spatial relationships between them.
In a fully connected layer, each neuron is connected to every single pixel of the image, which means the network has to learn a huge number of parameters for a 28 by 28 image 784 pixels.
A fully connected layer to a hidden layer with 128 neurons would require around 100,000 parameters just for one layer.
So this is why CNN is usually used for image classification, especially for larger image input.
This is a typical architecture of CNN.
CNN also does use fully connected layers, but only at the end of the network.
The most common and fundamental layers are convolution and pooling.
A complete convolutional layer in a CNN typically consists of the following steps.
Padding, which is optional.
Convolution bias.
Addition and activation function.
This is an illustration of how convolution process work.
Convolution is the process of sliding a small filter kernel over an input image, performing element wise multiplication and summing the results to produce a feature map.
In this illustration, we have a five by five image and a three by three kernel with a stride of one, resulting in a three by three feature map.
In a real CNN, we usually have more than one kernel, resulting in more than one feature. Map output.
In a CNN, a padding layer is an optional layer used to add extra pixels, usually zeros around the border of the input image or feature map.
Before applying the convolution operation, padding is used to control the output size.
Without padding, every convolution reduces the spatial size, height, and width of the feature.
Map padding ensures that the filter can center over the edge pixels too, allowing the model to learn from the entire image, not just the middle.
We can use this formula to calculate the output size of the feature map after the convolution process.
For example, if the image size is 28 by 28, the kernel size is five by five, the padding is zero, and the stride is one.

It consists of the convolution process, bias addition, and activation.
Function bias is a learnable parameter that is added to the result of the convolution operation.
The bias is usually added to the entire feature map after the convolution is applied.
After bias addition, the result is passed through an activation function like ReLU or sigmoid.
The activation function introduces non-linearity to the network, allowing it to learn more complex patterns.
ReLU is the most common activation in CNNs because it helps the model train faster and is simple to compute.
ReLU is mathematically defined by this equation.

Now let's move on to the pooling layer.
Pooling is a downsampling operation that reduces the spatial size of the feature map after convolution.
There are two primary types of pooling max pooling and average pooling.

For every two by two patch, we choose the maximum value.
If we use average pooling, then we average the numbers in every two by two patch.

ReLU is the most common activation in CNNs.
In pooling layers, max pooling is the most common pooling method in CNNs.
